TOKYO BROTHERHOOD LAB WEBSITE UPDATE

Included paths (replace/add these exact files in the repository):

1. docs/projects/whats-next.html
   Updated project landing page with detailed project information and links to the APK list.

2. docs/projects/whats-next/releases.html
   New nested APK Releases page. It reads the public What-Next GitHub Releases API, lists all attached .apk assets (newest first), and displays direct downloads, build dates, file sizes, release links, download counts, and SHA-256 digests when GitHub provides them. Debug-named packages are marked as test builds. It has a fallback link if the API cannot be reached.

3. docs/projects/tokyo-manga-lab.html
   Expanded project information and reduced logo sizing.

HOW TO APPLY
1. Download and extract the ZIP.
2. Open your repository: https://github.com/tokyo720022-create/tokyo-brotherhood-lab-site
3. Upload/replace the files at the paths shown above. Keep the docs/ folder structure.
4. Commit the changes to main. GitHub Pages is already configured to deploy from main /docs, so the site should update after the Pages build completes.

The release list reads from:
https://api.github.com/repos/tokyo720022-create/What-Next/releases

No APK is copied into the website repository; download buttons link to the original APKs attached to the What-Next GitHub releases. The release list will update automatically when APKs are attached to new releases.
