# Tokyo Brotherhood Lab

Official static project hub for Tokyo Brotherhood Lab.

## Website files

- `docs/index.html` — homepage
- `docs/assets/css/style.css` — site styles
- `docs/assets/js/main.js` — small interactions
- `docs/assets/images/` — project logos and images
- `docs/projects/` — reserved for future standalone project pages

## GitHub Pages setup

In repository Settings → Pages, select **Deploy from a branch**, choose `main`, and choose `/docs` as the folder.
