# Project pages

Standalone pages for each Tokyo Brotherhood Lab project.

- `whats-next.html` — What's Next overview
- `whats-next/releases.html` — APK release list (data from `../../data/releases.json`)
- `tokyo-manga-lab.html` — Tokyo Manga Lab overview

Shared styles live in `../assets/css/style.css`. See the root `README.md` for how to add a new project page.
